## 2. Ejes Temáticos y Competencias Profesionales Clave
1. **Technical Documentation & Software Specifications**
   * Production-grade API documentation (OpenAPI / Swagger 3.0 specification in English).
   * Writing clear, unambiguous system requirement specifications and architectural decision records (**ADRs**).
2. **Agile Engineering Communication**
   * Participating in international Agile ceremonies in English: Daily standup updates, sprint planning estimations, demo walkthroughs, and sprint retrospectives.
   * Asynchronous collaboration: Writing pull request descriptions, conducting constructive code reviews on GitHub, and drafting incident post-mortems.
3. **The Global Technical Interview**
   * Answering behavioral interview questions using the **STAR Method** (Situation, Task, Action, Result).
   * Explaining data structures, algorithms, and distributed system design trade-offs fluently in English.

## 3. Proyectos de Portafolio Recomendados

### Proyecto 1: Repositorio Open-Source Internacional con Documentación Técnica en Inglés (OpenAPI + ADRs + Contributing Guide)
* **Problema a Resolver:** Los ingenieros de software calificados en Latinoamérica pierden ofertas de empleo remotas globales ($3,000 - $7,000+ USD) por falta de un portafolio documentado en inglés técnico impecable.
* **Entregables Concretos:**
  1. **Especificación OpenAPI 3.0 completa en inglés:** Describiendo endpoints, schemas, payloads y códigos de error para un microservicio backend.
  2. **README.md de calibre internacional:** Incluyendo arquitectura, variables de entorno, Docker compose setup y performance benchmarks.
  3. **3 Architectural Decision Records (ADRs) en inglés:** Siguiendo la plantilla MADR justificando decisiones técnicas complejas.
* **Herramientas:** Swagger UI, Markdown, GitHub.

---

### Proyecto 2: Video-Simulación de Entrevista de System Design & Behavioral en Inglés (STAR Method)
* **Problema a Resolver:** Demostrar fluidez verbal técnica en inglés al explicar la arquitectura de un sistema y cómo se resolvieron incidentes en producción frente a evaluadores internacionales.
* **Entregables:**
  1. Video de 8 a 10 minutos (en Loom o YouTube oculto) resolviendo un reto de diseño de sistemas en una pizarra virtual en inglés.
  2. Glosario técnico personal y speech transcript estructurado.
* **Herramientas:** Loom, Excalidraw, Markdown.
